## AI Interviewer Agent ##

An AI-powered technical screening platform that conducts short voice-based interviews on behalf of recruiters, dynamically asks and evaluates technical questions, and produces structured candidate assessments.

**Stack:** TypeScript · Next.js · Fastify · PostgreSQL · Drizzle · Google AI SDK · Deepgram · ElevenLabs · WebSockets · Langfuse/OpenTelemetry

**What I built:** Designed and implemented the application end-to-end, including the interview lifecycle, realtime voice pipeline, backend architecture, persistence, recruiter/candidate interfaces and deployment.

**Technical challenge:** Maintaining a responsive conversational interview while coordinating speech-to-text, LLM reasoning and text-to-speech services, handling failures and latency without breaking the interview experience.
